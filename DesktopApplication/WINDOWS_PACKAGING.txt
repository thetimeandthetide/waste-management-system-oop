Windows Runnable / Installable Application Notes
================================================

Option 1: Simple Runnable JAR
-----------------------------
1. Install JDK 21 or newer on Windows.
2. Install MySQL on Windows.
3. On first launch the application creates the database and tables automatically.
   Alternatively, run sql/setup.sql first if you want to inspect the schema.
4. Keep this folder structure:
   WasteManagementSystem
   - dist/WasteManagementSystem.jar
   - lib/mysql-connector-j.jar
   - run.bat
5. Double-click run.bat.

Option 2: Build On Windows
--------------------------
1. Open Command Prompt inside the WasteManagementSystem folder.
2. Run:
   build.bat
3. Run:
   run.bat

Option 3: Create A Windows Installer With jpackage
--------------------------------------------------
Run this on Windows after building the JAR:

jpackage ^
  --type exe ^
  --name WasteManagementSystem ^
  --input dist ^
  --main-jar WasteManagementSystem.jar ^
  --main-class main.Main ^
  --app-version 1.0 ^
  --dest installer

Important:
- MySQL must still be installed and running on the target computer.
- The database must be created using sql/setup.sql.
- Configure credentials with WASTE_DB_USER and WASTE_DB_PASSWORD environment
  variables before running the application. Do not put real passwords in source.
