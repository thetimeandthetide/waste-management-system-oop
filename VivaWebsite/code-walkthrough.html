How To Run The Project

1. Start MySQL

brew services start mysql

This starts the MySQL server in the background. The Java app needs MySQL running before it can store or read data.

2. Open The Project Folder

cd /Users/josephfidel/Desktop/WasteManagementSystem

This moves Terminal into the project folder.

3. Run The App

./run.sh

This runs the packaged JAR file. The Swing desktop window opens.

4. Rebuild If Code Changes

./build.sh

This compiles the Java source files and recreates dist/WasteManagementSystem.jar.

How Swing Is Opened And Used

Swing does not open from HTML or a browser. It opens from Java code using a JFrame.

public static void main(String[] args)

This is the first method Java runs.

SwingUtilities.invokeLater(() -> { ... })

This tells Java to start the GUI on Swing's Event Dispatch Thread. Swing components should be created on this thread.

DatabaseManager.initializeDatabase();

Before the window opens, the app creates/checks the database and table.

WasteManagementGUI gui = new WasteManagementGUI();

This creates the main GUI object. Since WasteManagementGUI extends JFrame, this object is the desktop window.

gui.setVisible(true);

This displays the JFrame on the screen. Without this line, the window exists in memory but is not visible.

Model Package Code

The model package contains the OOP part of the project.

Waste.java
package model;

Places this class inside the model package.

public abstract class Waste

Defines an abstract parent class. Abstract means we cannot directly create a plain Waste object.

private int id;

Stores the database ID. It is private to show encapsulation.

private String description;

Stores the description entered by the user.

private double quantity;

Stores quantity in kilograms. double allows decimal values like 12.5.

private String location;

Stores where the waste is located.

private String status;

Stores Pending or Collected.

public Waste() { }

Default constructor. It allows creating an empty object if needed.

public Waste(int id, String description, double quantity, String location, String status)

Parameterized constructor. It fills all common fields at object creation time.

this.id = id;

Assigns the constructor id value to the object's id field.

public abstract String getWasteCategory();

Abstract method. Child classes must override it. This is abstraction and supports polymorphism.

getId(), setId()

Getter returns ID. Setter updates ID. This demonstrates controlled access to private data.

getDescription(), setDescription()

Getter and setter for description.

getQuantity(), setQuantity()

Getter and setter for quantity.

getLocation(), setLocation()

Getter and setter for location.

getStatus(), setStatus()

Getter and setter for status.

OrganicWaste.java
package model;

Build, Run, And Manifest Files

build.sh

Mac/Linux script that compiles and creates the JAR.

mkdir -p build dist

Creates build and dist folders if missing.

javac -cp "lib/mysql-connector-j.jar" -d build ...

Compiles Java code and includes the MySQL driver.

jar cfm dist/WasteManagementSystem.jar manifest.txt -C build .

Creates the runnable JAR using manifest settings.

run.sh

Runs the built JAR on Mac/Linux.

java -jar dist/WasteManagementSystem.jar

Starts the application.

build.bat / run.bat

Windows versions of the build and run scripts.

manifest.txt

Tells the JAR which class is the main class and where the connector jar is.

Main-Class: main.Main

When the JAR runs, Java starts from main.Main.

Class-Path: ../lib/mysql-connector-j.jar

Lets the JAR find the MySQL JDBC driver.

How To Check MySQL Database And Data

Open MySQL Terminal

mysql -u root

Commands Inside MySQL

SHOW DATABASES;
USE waste_management_db;
SHOW TABLES;
DESCRIBE waste;
SELECT * FROM waste;
SELECT * FROM waste WHERE status = 'Collected';
SELECT * FROM waste WHERE waste_type = 'Organic';
exit;

One-Line Terminal Check

mysql -u root -e "USE waste_management_db; SELECT * FROM waste;"

Use this to prove during viva that the GUI data is actually stored in MySQL.
