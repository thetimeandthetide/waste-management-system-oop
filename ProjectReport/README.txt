WASTE MANAGEMENT SYSTEM PROJECT REPORT
======================================

main.pdf is the generated report. Review identifiers and obtain every member's
signature on printed page i before submission. The supplied UI screenshots
were captured before the latest approval/button fixes, so they were not
included as evidence; capture updated screens from the rebuilt application if
the department requires screenshots in the results section. main.tex is the editable LaTeX source
structured from the supplied OOP report template. bibli.bib contains the cited
technical references, and figures/image14.jpg is the college emblem used on
the cover.

build_report.py regenerates main.pdf with Python and ReportLab and includes the
current Java source files from ../DesktopApplication/src in the appendix:

    python3 build_report.py

The report's technical descriptions and source listing are based on the current
desktop application, not the earlier presentation's outdated feature summary.
The presentation PDF was used only for member names, KTU IDs, and roll numbers.
